# Bored Jar Homebrew tap

```bash
brew install --cask boredjar-com/tap/splix-macos
```

| Cask | What |
|------|------|
| `splix-macos` | [SpliX for macOS](https://github.com/boredjar-com/splix-macos): Samsung / Xerox / Dell SPL (QPDL) printer driver for macOS 27 on Apple Silicon. Signed and notarized installer. |
